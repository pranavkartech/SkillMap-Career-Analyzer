# SkillMap — Career Skills Analysis and Learning Planner

SkillMap is a Python and Streamlit application that helps users assess their current skills, compare them with career requirements, identify skill gaps, and create a structured learning plan.

## Features

- Career skill profile and confidence ratings
- Skill matching against selected career roles
- Job description analysis
- Visual skill coverage summary
- Suggested practice activities
- Weekly learning plan
- Downloadable skill reports

## Technology Stack

- Python
- Streamlit
- Plotly
- Pandas

## Run Locally

1. Install Python.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Start the application:

   `streamlit run app.py`

## Project Purpose

SkillMap is designed to help users understand the skills required for their target careers and organize their learning priorities.
